This module is a flat GitHub-specific configuration directory with no executable code. It consists of: `dependabot.yml` declaring weekly update schedules for `github-actions` and `nuget` ecosystems; `CODEOWNERS` mapping source directories (Trackdub.Application, Infrastructure, Inference, Media, Domain, Contracts, build files, and `.github/**`) to the `@mesalimllc/maintainers` team for automatic PR review assignment; `FUNDING.yml` linking to GitHub (`canopy-lions`) and Ko-fi (`trackdub`) sponsorship channels; and `pull_request_template.md` providing a structured checklist covering testing commands (`dotnet build/test Trackdub.slnx -m:1 -p:Platform=x64`), architecture review gates, license/model impact, risk assessment, and milestone/agent notes. The `ISSUE_TEMPLATE/`, `codeql/`, and `workflows/` subdirectories are present in the repo tree but currently empty or not materialized in this snapshot.
