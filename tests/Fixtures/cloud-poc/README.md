Reproduction (developer tools only; no inference/GPU required):

```sh
espeak-ng -v en-us -s 140 -w source.wav 'The train leaves at noon. Please bring the blue bag. We will meet near the station.'
ffmpeg -f lavfi -i color=c=navy:s=640x360:r=25 -i source.wav -c:v libx264 -preset veryfast -pix_fmt yuv420p -c:a aac -b:a 96k -shortest -map_metadata -1 en-speech.mp4
```
